## 🌐 Live Website & GitHub Pages Deployment

This repository is optimized to serve as a fast, responsive, zero-dependency CV & Portfolio site hosted directly on **GitHub Pages**.

### One-Click GitHub Pages Setup
1. Push this repository to your GitHub account under your desired name (e.g., `dreamkatana.github.io` or `cv`):
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of recruiter-focused dark portfolio"
   git branch -M main
   git remote add origin https://github.com/dreamkatana/<repo-name>.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Navigate to **Settings** &rarr; **Pages** (under the "Code and automation" sidebar).
   - Under **Build and deployment** &rarr; **Source**: Select **Deploy from a branch**.
   - Under **Branch**: Select `main` (or `gh-pages`) and folder `/ (root)`.
   - Click **Save**.
3. Within 1–2 minutes, your CV will be live at `https://dreamkatana.github.io/<repo-name>/`!
